# Toy learning workflow: explanation and practice
Authored classroom fixture, version 1.

A learner first states a topic, prior knowledge, and a learning goal. An explanation can use a definition, one worked example, and a limitation, with links to supporting evidence. To check application rather than only recognition, ask a new practice question and wait for the learner's attempt. Feedback should discuss the actual response, not an invented answer. When requested explicitly, a solution can be shown. An uncertain or incomplete answer is not a basis for declaring mastery.

A small progress record may contain the question asked, the learner's verbatim attempt, the assistant's feedback, and the evidence used to check it. An unanswered question remains pending. The learner can correct a stated preference or goal. Logging these events does not establish an improvement in learning outcomes.
