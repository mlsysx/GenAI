# Toy grounding lesson: claims and source IDs
Authored classroom fixture, version 1.

Checking that a citation ID exists is different from checking that its passage supports a claim. A generated answer can cite a real source but misstate its content, omit an exception, or use an obsolete version. For a source-grounded learning task, inspect each factual claim and compare it to the cited passage or visual region. Preserve titles, page or section locators, dates, versions, and original versus generated status.

Generated captions and image observations are derived content, not automatic ground truth. A report should identify its evidence and any unresolved uncertainty. An exact number that cannot be read from a chart should not be invented. Request a clearer image or state that the value cannot be determined reliably from the current evidence.
